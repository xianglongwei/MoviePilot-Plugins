# 0001: 用本地元数据登记作为 PigGo 儿童动画识别兜底

日期：2026-08-30

## Status

Proposed

## Context

PigGo 儿童区存在很多 TMDb 缺少的儿童动画、科普和低龄节目。MoviePilot 的默认流程依赖媒体识别，识别失败会影响下载后的整理和入库。PigGo 详情页本身提供了标题、副标题、集数、年份、简介、封面、分辨率、来源、制作组等可用于媒体库展示的字段。

## Decision

第一版插件不伪造 TMDb ID，也不直接修改 MoviePilot 核心识别链。插件维护自己的本地媒体条目，把 PigGo 站点条目解析成可人工校正的本地元数据，并在整理入库时生成标准目录、文件名、NFO 和图片，让 Emby/Jellyfin 读取本地元数据。

## Consequences

这样做更稳，能绕开 TMDb 数据缺失，同时减少对 MoviePilot 内部识别实现的耦合。代价是插件需要自己维护本地条目、人工校正状态和整理任务，并且需要在真实 MoviePilot 宿主里验证下载完成事件、文件路径和媒体服务器刷新能力。
