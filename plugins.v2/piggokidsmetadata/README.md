# PigGoKidsMetadata V2

当前版本 `0.3.0` 提供与 V3 一致的 RSS 候选、粘贴链接、MoviePilot 下载提交、hash 任务恢复、安全内容包扫描、只读 TMDb 严格匹配和可选整理流程。

V2 没有 V3 等价的动态媒体来源合同，因此兼容层将高置信度本地元数据直接传给 MoviePilot V2 整理链；仅当 MoviePilot 返回标题或别名、类型以及已有年份/季信息均不冲突的 TMDb 结果时沿用其真实身份，不伪造任何公共来源 ID。插件不会直接移动文件，自动整理默认关闭。

插件可从已脱敏识别决策生成只读 TMDb 贡献草稿；草稿只包含建议字段和相对路径证据，不会自动提交公共数据库。

## 使用方式

1. 启用插件并填写 MoviePilot 容器内可见的下载根目录。
2. 可选填写一个或多个 PigGo RSS/Atom 地址；没有 RSS 时可粘贴磁力或下载链接。
3. 刷新候选并由用户显式选择下载。
4. 插件记录下载 hash，监听宿主整理事件，并轮询下载器恢复遗漏状态。
5. 下载完成后解析真实 NFO、图片、字幕和文件名；冲突项目进入待处理。

完整私密下载引用不会写入候选或任务记录。插件重启后，RSS 候选可通过再次刷新恢复引用；手工粘贴的私密链接需要重新粘贴。

手工扫描接口继续保留：

```text
POST /api/v1/plugin/PigGoKidsMetadata/scan
```

```json
{
  "relative_path": "Kids/Example.Show.S01",
  "site_item_id": "30876",
  "download_hash": "0123456789abcdef0123456789abcdef01234567"
}
```

扫描路径必须相对于下载根目录；插件拒绝上级目录跳转和符号链接逃逸。
